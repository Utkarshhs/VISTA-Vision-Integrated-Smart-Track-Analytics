# VISTA - Vision Integrated Smart Track Analytics

VISTA is an advanced, AI-powered predictive maintenance platform designed for modern railway infrastructure. It bridges the gap between regional controllers and on-site field engineers by providing real-time component health tracking, intelligent task assignment, and automated visual defect analysis using the Gemini Vision AI.

The platform is divided into two seamlessly integrated environments:
1. **The Regional Controller Dashboard:** A robust web interface for tracking network health and assigning tasks.
2. **The Field Engineer PWA:** A mobile-first Progressive Web App used by engineers on the ground to receive tasks, conduct repairs, and perform AI-assisted visual verifications.

---

## 🌟 Key Features

### Regional Controller Dashboard (Web)
- **Interactive Sector Map:** Visualize railway components by location and Health Score (CII - Component Integrity Index).
- **Direct Assignment:** Instantly assign field engineers to critical components directly from the map, bypassing cumbersome dispatch queues.
- **Real-Time Sync:** Powered by Firebase Firestore, see assignments transition from "In Progress" to "Completed" live.
- **AI Verification Hub:** Review incoming repair photos and read the AI's diagnostic verification report (generated by Gemini Vision) before officially closing an issue.

### Field Engineer PWA (Mobile)
- **Task Broadcast & Acceptance:** Receive incoming repair tasks pushed directly to the engineer's device.
- **In-Field AI Analysis:** Upload a photo of the repaired component to instantly trigger a cinematic AI scanning sequence. The Gemini Vision API detects surface defects, wear patterns, and calculates safety risks locally before submission.
- **Seamless Handoff:** Submit the photo, engineer feedback, and AI analysis back to the Controller Dashboard for final approval.
- **Premium UI:** Built with TailwindCSS and React, featuring glass-morphism, fluid animations, and a sleek dark-mode aesthetic.

---

## 🏗️ Architecture & Tech Stack

VISTA is built across two specialized codebases:

### 1. `VISTA-Vision-Integrated-Smart-Track-Analytics-webpage/` (The Dashboard)
- **Frontend:** Vanilla HTML5, CSS3, JavaScript. No heavy frameworks, ensuring blazing-fast load times.
- **Styling:** Custom CSS with modern variables, dynamic color themes (Crimson Red / Dark Mode), and interactive charts (Canvas API).
- **Backend/DB:** Firebase Authentication and Firestore (Real-time).

### 2. `engineer-app/.../railtrack/` (The Field PWA)
- **Frontend:** React 18, TypeScript, Vite.
- **Routing:** Wouter (lightweight routing for fast PWAs).
- **Styling:** TailwindCSS with shadcn/ui components and Lucide-react icons.
- **Backend/DB:** Firebase Firestore for synchronization with the Dashboard.

### 🧠 AI Engine
- **Powered by Google Gemini (gemini-1.5-flash):** Both platforms utilize the Gemini Vision API for image analysis. The AI is prompted with strict JSON output schemas to generate highly structured, predictable diagnostics for railway infrastructure (e.g., detecting micro-fractures, fastener wear, ballast condition).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+) for the Engineer PWA.
- A Firebase Project (with Firestore and Authentication enabled).
- A Google Gemini API Key.

### 1. Setting up the Dashboard
1. Navigate to `VISTA-Vision-Integrated-Smart-Track-Analytics-webpage/`.
2. Copy `config.example.js` to `config.js` and insert your Gemini API Key. (Note: `config.js` is gitignored to protect your key).
   \`\`\`javascript
   window.VISTA_CONFIG = {
       GEMINI_API_KEY: "your_api_key_here"
   };
   \`\`\`
   *Alternatively, if you deploy without a config.js, the dashboard will prompt you to securely enter your key in the browser on the first load.*
3. Update `firebase-config.js` with your Firebase project credentials.
4. Serve the directory using any static file server (e.g., Vercel, Netlify, or `npx serve`).

### 2. Setting up the Engineer PWA
1. Navigate to the React application directory (`engineer-app/.../railtrack/`).
2. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
3. Create a `.env.local` file in the root of the PWA directory and add your Gemini API Key:
   \`\`\`env
   VITE_GEMINI_API_KEY=your_api_key_here
   \`\`\`
4. Start the development server:
   \`\`\`bash
   npm run dev
   \`\`\`

---

## 🔒 Security Notes
- **API Keys:** The Gemini API keys have been completely removed from the source code. The PWA uses Vite environment variables (`.env.local`), and the dashboard uses a gitignored `config.js` or `localStorage`. **Never commit your API keys.**
- **Demo Mode Resilience:** The Gemini integration includes graceful local-fallback mechanisms. If API quota is exceeded during a live presentation, the system will seamlessly intercept the 429 error and generate randomized, highly realistic placeholder data (scores between 70-85, minor threat generation) to ensure demonstrations never fail.

## 👨‍💻 Deployment
Both applications are optimized for edge deployment on platforms like Vercel:
- **Dashboard:** Deploy as a static site.
- **PWA:** Deploy using the Vite framework preset. Ensure you add `VITE_GEMINI_API_KEY` to your Vercel Environment Variables.
